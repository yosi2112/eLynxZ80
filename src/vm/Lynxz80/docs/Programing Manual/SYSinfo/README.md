# LynxZ80Sim System Information

LynxZ80Sim のシステム構成図と概要。本文書は検索用の要約とブロック別メモを兼ねる。

## 全体アーキテクチャ

本システムは、メインCPU系とサブCPU系に分離された構成である。メインCPU系はシステム制御、主記憶、FDD、シリアル、タイマ、リセットなどの周辺制御を担当する。サブCPU系は主に表示制御を担当し、文字表示系とグラフィック表示系を制御して最終的な映像出力を生成する。

メインCPU系とサブCPU系は、メイン-サブCPUインターフェースを介して接続される。表示処理の負荷をサブCPU側へ分離することで、メインCPU側の処理と表示生成を分担する設計になっている。

## ブロック別役割

| ブロック | 主要デバイス | 役割 |
|---|---|---|
| メインCPU系 | Z80A CPU, Z80A DMA | 全体制御、DMA転送、バス制御 |
| メインメモリ系 | ROM, RAM | プログラム格納、作業データ保持 |
| フロッピーディスク制御 | MB8877A FDC, Z80A PIO | FDD制御、データ入出力 |
| シリアル/タイマ/リセット | Z80A SIO, Z80A CTC | 通信、タイミング制御、外部入力、初期化 |
| サブCPU系 | Z80A CPU, サブROM, サブRAM | 表示処理管理、メイン系とのデータ交換 |
| 文字表示系 | uPD7220A系 GDC, テキストRAM, キャラクタジェネレータ | 文字表示生成 |
| グラフィック表示系 | uPD7220A系 GDC, グラフィックRAM | 図形、ドット表示生成 |
| 映像出力 | RGB, HSYNC, VSYNC | 最終的な表示信号出力 |

## 動作の流れ

1. 起動時にメインCPUがROMからプログラムを実行する。
2. メインRAMを作業領域として使用する。
3. 必要に応じて FDD やシリアルI/Oを制御する。
4. 表示データや表示命令をメイン-サブCPU間で受け渡す。
5. サブCPUが文字系/グラフィック系へ表示処理を指示する。
6. 映像出力回路が RGB と同期信号を生成し、表示装置へ出力する。

## 設計上の特徴

- CPU系と表示系を分離した構成。
- 文字表示とグラフィック表示を独立した系で実装。
- DMAや専用I/Oデバイスにより周辺制御を効率化。
- FDD、シリアル、タイマ、リセットを機能単位でモジュール化。
- 回路図が機能ブロック単位で分かれており、保守と解析がしやすい。

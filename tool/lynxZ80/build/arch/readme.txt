# CP/M 2.2 External Archives

Place the following externally obtained archives in this directory before preparing the CP/M 2.2 build environment:

```text
cpm2-asm.zip
cpm22-b.zip
```

- `cpm2-asm.zip` supplies the CP/M 2.2 assembly source used to obtain `CPM22.Z80`.
- `cpm22-b.zip` supplies standard CP/M command binaries used by the build scripts.

These archives are not distributed with eLynxZ80. Confirm the source and applicable redistribution terms before use.

For the current build procedure and known path mismatches, see:

```text
tool/lynxZ80/README.md
Requirements_JP.md
```

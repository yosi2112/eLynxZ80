## フォントROMについて

このリポジトリでは、`KH-Dot-Dougenzaka-16.ttf` および生成済みのフォントROMデータを再配布していません。

フォントROMをビルドする場合は、配布元から `KH-Dot-Dougenzaka-16.ttf` を別途ダウンロードし、ビルドスクリプトが指定する場所に配置してください。

`KH-Dot-Dougenzaka-16.ttf` は、SIL Open Font License 1.1 に基づき別途ライセンスされています。

このフォントから生成されたフォントROMデータを再配布する場合、そのデータも同ライセンスに基づくものとして扱ってください。
